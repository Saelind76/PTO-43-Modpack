# Source files

Text sources of the modpack (Lua, LOD and wake definitions), mirroring the installed folder
`Mods/tech/0_PTO'43 Modpack`.

3D models, textures, sounds and missions are **not** stored in git: download them from
[Releases](https://github.com/Saelind76/PTO-43-Modpack/releases). This folder alone is not a working mod.

Bug reports can point to the exact file and line here. See [CHANGELOG.md](../CHANGELOG.md).
