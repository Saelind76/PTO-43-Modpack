# [PTO'43] Modpack

Open, non-commercial community modpack for **DCS World** recreating the Pacific Theater of Operations, 1943.
Created by Team PTO '43 (Hawkeye60 & Saelind76).

## Contents

### Aircraft
- Bell P-39N Airacobra
- Curtiss P-40M Warhawk
- Grumman F4F-4 Wildcat
- Grumman F6F-3 Hellcat
- Vought F4U-1
- Lockheed P-38G Lightning II
- Douglas SBD Dauntless
- Grumman TBF-1 Avenger
- North American B-25C/D Mitchell
- Consolidated PBY-5 Catalina
- Mitsubishi A6M3 Model 32 Hamp
- Nakajima Ki-43-II Hayabusa (Oscar)
- Kawasaki Ki-61-I Hien (Tony)
- Nakajima Ki-44 Shoki (Tojo)
- Nakajima B5N2 Kate (in development)
- Aichi D3A2 Val
- Mitsubishi G4M2 Betty
- Mitsubishi Ki-21-II Sally
- Nakajima B6N1 Jill
- Yokosuka D4Y Judy
- Kawanishi H8K2 Emily
- Project Ki-45 Toryu

### Naval
- GRL ships
- USN: CV Saratoga, CVL Independence, BB Massachusetts, BB Alabama, DD Cassin Young, CA Baltimore class, CL Cleveland class, submarines
- IJN: CVL Zuiho, CV Shokaku, CA Kumano, BB Nagato, CL Nagara, CL Isuzu, DD Ayanami, submarines, torpedo boat, Daihatsu landing class

### Ground units
- General ground units
