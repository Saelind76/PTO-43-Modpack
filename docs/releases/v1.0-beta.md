# [PTO'43] Modpack — BETA 1.0

**The Pacific, 1943.** Aircraft, warships and a shared weapons & sensors core for DCS World.

## ⬇️ Download and install — two steps

| Step | File | Size |
|---|---|---|
| **1. Full mod** | `PTO43_Modpack_BETA_1.0.zip` (below, under **Assets**) | ~1.2 GB |
| **2. Latest hotfix** | **[HOTFIX 1.0.1](https://github.com/Saelind76/PTO-43-Modpack/releases/tag/v1.0.1-beta)** | ~134 MB |

Hotfixes are **cumulative**: you only ever need this full package plus the **latest** hotfix. What changed in each version: **[CHANGELOG](https://github.com/Saelind76/PTO-43-Modpack/blob/main/CHANGELOG.md)**.

### Requirements
- DCS World
- WWII Assets Pack

### Installation
- **OVGME / mod manager:** add the `[PTO'43] Modpack` folder from the zip as a mod. Extract the hotfix over that same mod folder (overwrite), then enable it.
- **Manual:** copy the `Mods` folder inside `[PTO'43] Modpack` into `Saved Games\DCS\`. Then do the same with the hotfix and overwrite.

⚠️ Do **not** run this pack together with the Community PTO Pack: both define some of the same unit types (`Akizuki_DD`, `TypeC_Cargo`, `Cimarron_Oiler`, `Dale_Tanker`).

## 🧪 This is a beta
This release is for testing and bug hunting. **Every comment is appreciated** — please open an [Issue](https://github.com/Saelind76/PTO-43-Modpack/issues) and tell us:
1. The unit or mission involved
2. What happened and what you expected
3. A screenshot, and your `dcs.log` if DCS reported an error

The Lua sources are in [`src/`](https://github.com/Saelind76/PTO-43-Modpack/tree/main/src), so you can point to the exact file and line.

**1.0 without the hotfix has important weapon bugs** (for example, Japanese bombs and torpedoes cannot be loaded). Install the latest hotfix.
